### О проекте

Данный репозиторий содержит материалы исследовательского проекта, посвященного выбору оптимального бесплатного хостинга для учебных задач. В ходе работы были проанализированы 10 популярных платформ, оценены их технические ограничения и построены визуализации.

**Цель проекта:** определить лучший бесплатный хостинг для статического учебного сайта и обосновать выбор.

### Ключевые результаты

В результате сравнительного анализа было установлено, что для статического учебного проекта оптимальным выбором является **GitHub Pages**. 

**Основные преимущества выбора:**
1. Бесплатное размещение без рекламы.
2. Автоматическое обновление при каждом `git push`.
3. Лимит трафика в 100 ГБ/мес, которого достаточно с запасом.
4. Нативная поддержка Markdown и Mermaid.

Если в будущем возникнет необходимость в серверной логике (PHP/MySQL), в качестве альтернативы рассмотрены платформы InfinityFree и AwardSpace.
