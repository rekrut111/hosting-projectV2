## 1. Введение и актуальность

> Хостинг — это базовая инфраструктурная услуга, без которой невозможно существование современного веб-сайта в глобальной сети.

Хостинг представляет собой услугу размещения файлов сайта на сервере, который подключён к интернету круглосуточно и имеет постоянный IP-адрес. Без хостинга сайт существует исключительно на локальном компьютере разработчика и недоступен другим пользователям. Бесплатный хостинг позволяет разместить сайт без денежных затрат, однако накладывает существенные ограничения на вычислительные ресурсы, поддерживаемые технологии и стабильность работы.

В рамках данного проекта я рассмотрел десять бесплатных хостинг-платформ, сравнил их по ключевым параметрам, выделил объективные достоинства и недостатки, а также определил, какой вариант является оптимальным для учебного статического сайта. Отдельно я проверил, как работает размещение проекта прямо на GitHub Pages — без сторонних серверов и без платных тарифов.

**Цель проекта:** определить лучший бесплатный хостинг для учебного проекта и обосновать выбор.

**Задачи проекта:**
1. Изучить, что такое хостинг и какие бывают типы хостинга.
2. Составить список доступных бесплатных хостинг-платформ.
3. Сравнить платформы по параметрам: поддержка языков, лимиты, стабильность, наличие рекламы.
4. Построить таблицы и диаграммы для наглядности.
5. Сделать вывод и выбрать лучший вариант.

## 2. Методика сравнительного анализа

Для того чтобы сравнение было объективным, все платформы оценивались по единому набору критериев. Оценка проводилась на основе официальной документации и страниц тарифов по состоянию на ноябрь 2026 года [1], [2].

**Критерии оценки:**
1. **Поддержка технологий** — наличие интерпретатора PHP и системы управления базами данных MySQL. Для статического сайта не требуется, но учитывалось как фактор гибкости и возможности масштабирования.
2. **Лимит трафика** — достаточность бесплатного объёма для сайта с посещаемостью до 1000 уникальных пользователей в месяц.
3. **Стабильность** — наличие или отсутствие принудительной остановки («засыпания») при простое.
4. **Наличие рекламы** — наличие принудительных вставок на страницах пользователя.
5. **Коммерческое использование** — разрешено ли использовать бесплатный тариф для проектов, приносящих доход.

## 3. Теоретическая часть: классификация хостингов

Хостинг можно разделить на несколько типов, каждый из которых решает свой класс задач.

- **Статический хостинг** — отдаёт готовые файлы (HTML, CSS, JS, изображения). Серверная логика отсутствует. Это самый быстрый и надежный вариант.
- **Хостинг с поддержкой PHP/MySQL** — позволяет запускать скрипты и работать с базами данных. Подходит для динамических сайтов, CMS (например, WordPress).
- **VPS/VDS** — виртуальный сервер, где пользователь сам настраивает окружение. Требует навыков администрирования.
- **Serverless-платформы** — позволяют запускать отдельные функции без управления сервером. Идеальны для микросервисов.

Для учебного проекта чаще всего достаточно статического хостинга: он проще, быстрее и не требует администрирования.
