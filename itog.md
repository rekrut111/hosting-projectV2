# Итог: что я выбрал

Я выбрал **GitHub Pages**.

Причины:
1. Код уже на GitHub — не надо никуда переезжать.
2. Бесплатно и без рекламы.
3. Мой немецкий сервер не тратится на статику.
4. Таблицы в Markdown работают из коробки.
5. Лимит в 100 ГБ/мес — это мягкое ограничение, которого хватит с запасом.

## Что дальше

Если когда-нибудь понадобится PHP — придётся уходить с GitHub Pages. Но для школьного проекта и портфолио этого хватит. В случае необходимости можно посмотреть в сторону [InfinityFree](https://www.infinityfree.com/) (поддерживает PHP 8.2 и MySQL, без рекламы) или [AwardSpace](https://www.awardspace.com/free-hosting/) (5 ГБ трафика в месяц, PHP 8.x).
