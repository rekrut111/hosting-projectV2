# Сравнение бесплатных хостингов: плюсы и минусы

Данный файл содержит детализированную таблицу с преимуществами и недостатками рассмотренных платформ.

| Сервис | Плюсы | Минусы | PHP? |
|--------|-------|--------|------|
| **[GitHub Pages](https://pages.github.com/)** | Бесплатно, не засыпает, HTTPS, git push, 100 ГБ/мес | Только статика, нет PHP/MySQL, коммерческое использование запрещено | ❌ |
| **[Cloudflare Pages](https://pages.cloudflare.com/)** | Трафик не ограничен, serverless-функции, 500 сборок/мес | Нет классического PHP, для новичка сложно | ❌ |
| **[InfinityFree](https://www.infinityfree.com/)** | PHP 8.2 + MySQL, 5 ГБ SSD, без рекламы, неограниченный трафик (50k хитов/день) | Медленно, нет поддержки, нестабильно | ✅ |
| **[Vercel](https://vercel.com/)** | Хорош для React/Next.js, 100 ГБ/мес | Только личное использование, PHP нет | ❌ |
| **[Netlify](https://www.netlify.com/)** | 100 ГБ/мес, 300 минут сборки | PHP нет | ❌ |
| **[Render](https://render.com/)** | 750 часов/мес | Засыпает через 15 минут простоя, карта нужна | ❌ |
| **[AwardSpace](https://www.awardspace.com/free-hosting/)** | PHP 8.x, MySQL, 5 ГБ/мес, без рекламы | Мало места (1 ГБ), лимит трафика быстро расходуется | ✅ |

**Вывод:** если сайт статический — GitHub Pages. Если нужен PHP — придётся смотреть в сторону InfinityFree или AwardSpace, но это сопряжено с компромиссами по скорости и стабильности.
